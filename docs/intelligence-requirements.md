# Intelligence Requirements

## Fictional Organization

Northstar Regional Health is a fictional regional healthcare network consisting
of three hospitals, eight outpatient clinics, a public-health laboratory,
remote employees, internet-facing services, and cloud-based administrative
systems.

## Primary Intelligence Requirement

Which actively exploited vulnerabilities present the greatest near-term
operational risk to a mid-sized healthcare organization?

## Supporting Intelligence Questions

1. Which affected products could be present in a healthcare environment?
2. Which vulnerabilities affect internet-facing or remote-access technology?
3. Which vulnerabilities are reportedly associated with ransomware campaigns?
4. Which vulnerabilities could cause significant clinical or administrative disruption?
5. Which vulnerabilities should receive priority remediation during the next 30 days?
6. What important information is unavailable or uncertain?

## Intended Audience

- Chief Information Security Officer
- Vulnerability management team
- Security operations team
- Information technology leadership
- Healthcare operations leadership

## Intelligence Use

The assessment is intended to support defensive vulnerability prioritization.
It is not intended to provide exploitation instructions or offensive security guidance.

## Scope

The initial analysis covers CISA Known Exploited Vulnerabilities added from
January 1, 2026, through June 30, 2026.

## Limitations

This is a portfolio project based on publicly available information and a
fictional organization. It does not use internal asset inventories, scanner
results, network logs, medical records, or confidential information.
